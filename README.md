# QR-code-generator

This is a simple and responsive QR Code Generator built using HTML, CSS, and JavaScript. It allows users to generate QR codes for any input text, URL, or contact information with just one click. The project is useful for creating QR codes for personal, educational, or business purposes.

Features

Generate QR codes instantly

Input can be text, link, or any data

Responsive and clean UI

Download QR code as an image (optional feature)


Technologies Used

HTML for structure

CSS for styling

JavaScript for functionality (with qr-code-styling or qrcode.js library if used)


How to Use

1. Enter the text or URL you want to convert to a QR code.


2. Click the "Generate" button.


3. The QR code will appear below the input box.


4. (Optional) Click "Download" to save the QR code as an image.
